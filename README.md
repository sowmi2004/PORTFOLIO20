## Overview

This repository now contains a single project: a modern, dark-themed personal portfolio for **Sowmiya Devi**, a **Frontend Angular Developer** with 4+ years of experience building and migrating enterprise-scale applications using Angular and TypeScript.

The live site focuses on:
- **Growth** and continuous learning  
- **Vision** for advanced Angular architecture  
- **Ambition** to work on complex, product-based applications  
- **Remote-ready professionalism** and collaboration  
- **Future career direction** toward scalable enterprise frontends  

All content is rendered dynamically on the client using **TypeScript** and **template literals**, with styling via **Tailwind CSS** and a small amount of custom CSS. There is no Angular runtime here—this is a static site.

For detailed setup and deployment instructions, see `portfolio/README.md`.
